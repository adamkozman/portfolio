A useful coffee-shop website.

Koffee Kozman is an individual frontend project built with HTML, CSS, and JavaScript. It combines an espresso-brown and cream visual theme with a menu, shop story, and Montréal visit section.

The project focuses on the small interactions that make a website easier to use, rather than adding a framework to a page that doesn’t need one.

How it works

  • Browse a 14-item sample menu. Items include CAD prices and are grouped into coffee, other drinks, and bakery categories.
  • Filter by category. JavaScript shows the selected group and updates both the button state and item-count feedback.
  • Navigate on a small screen. A mobile menu supports keyboard focus and closes with Escape.
  • Check opening hours. The open/closed indicator uses Montréal time and the configured sample schedule.

Frontend details that matter.

Semantic HTML
Sections, headings, navigation, and menu items give the page a clear structure.
Custom CSS
Responsive layouts, typography, focus styles, and the coffee-shop color palette.
JavaScript
Category filters, mobile navigation, and the timezone-aware opening-hours indicator.

Progressive enhancement: the menu is in the HTML, so customers can still read it if JavaScript is unavailable. Filtering is an added convenience, not a requirement for access.

Current scope & next steps

The frontend is in progress and the source repository is private. Menu prices, contact details, and opening hours are sample content.

Planned work includes confirming shop information, refining accessibility and mobile behavior, and publishing the site. Ordering, a staff dashboard, and drink recommendations are future ideas—not implemented features.
