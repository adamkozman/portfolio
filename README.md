# Adam Kozman — Portfolio

Static personal portfolio hosted on GitHub Pages.

## Editing

- `index.html`: homepage, selected work, about, skills, and contact.
- Each featured project has a standalone HTML detail page.
- `java-foundations.html`: earlier Java work.
- `style.css`: shared responsive styles.
- `cv.pdf`: current supplied résumé. Replace this file to update every résumé link; preserve the filename.
- JPG files are application screenshots. SVG project overviews are labeled diagrams, not screenshots.

No build step or JavaScript dependency is required. Keep all files at the repository root. When changing CSS, update the stylesheet query version in each HTML page so returning visitors receive it.

## Content
